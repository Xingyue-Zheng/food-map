解决大学城学生的选择困难症
今天吃什么 · 大学城美食地图

> 专为大学城学生设计的美食决策工具，告别选择困难症。

🔗 在线体验： https://xingyue-zheng.github.io/food-map/

 项目背景

某高校联盟（5所大学）周边聚集了大量餐饮商户，但学生普遍面临
"吃什么"的决策困境——信息分散、缺乏针对学生群体的本地化美食指南。

本项目用一个网页应用解决这个问题。

核心功能

👈 食欲翻牌
探探式左右滑动交互，看着美食图片靠本能做决定。
右滑"想吃"后直接弹出导航和人均价格。

🎲 帮我选
选择当前心情（超级饿 / 累了一天 / 快穷了……）和预算，
系统智能匹配最合适的餐厅并说明推荐理由。

🔥 热搜榜
实时热度排行 + 学生口碑标签，比如：
- 「辣界天花板·不哭不算赢」
- 「带对象必成功·成功率87%」
- 「凌晨3点还亮灯·大学城守夜人」

🔍 探索
按分类、价格、距离、评分筛选全部餐厅。


 技术实现

- 纯 HTML / CSS / JavaScript，无任何框架依赖
- 单文件部署，托管于 GitHub Pages
- 支持移动端手势滑动
